# 游戏方案 · 当前方向

## 定位

有趣的休闲经营与客人收集游戏。老板小葵喜欢旅行；客人有短小、有梗的人物小传，不以复杂文学故事推动进度。

主循环：闯关营业 → 获得金币 → 解锁客人图鉴 → 购买带轻加成的装饰 → 前往下一站。

地图顺序：东南亚海岛（南风岛）→ 北欧极光峡湾 → 希腊古城 → 星际。全游戏计划20个结局称号，第四地图触发；当前不开发后续地图和结局。

## 当前范围

Unity 6000.0.62f1，C# / uGUI。第一地图目标4天、每天120秒、7客位＋1出酒口、9位客人、3件装饰。现已编写首日服务与部分收集/购买功能；不等于第一地图完成。

角色、场景和 UI 参考见 Art/Approved；运行素材以 UnityProject/Assets/Resources 为唯一引用来源。

小葵默认服装保留，各地图计划有对应服装，商店未来可购买。换装尚未列为本轮实现内容。

## 客人服务、对话与图鉴（2026-09-29 21:10 用户确认）

本节是当前玩法及客人素材范围，覆盖历史文档中冲突的表现要求。这里只更新设计与交接，不表示代码已经完成修改。引擎迁移和可玩版本以开发进度为准，上文Unity范围为原工程记录。

### 营业中的服务流程

客人入座 → 玩家点单 → 饮品自动排队制作 → 玩家在出酒口取杯 → 送达对应客位 → 客人饮用 → 玩家收钱 → 客人离场。玩家一次手持一杯，饮品绑定访客订单；实际收款才计收入并按现行规则解锁图鉴。每张地图的客流、目标金额与特殊机制单独配置，既有南风岛规则见[MAP01_RULES.md](MAP01_RULES.md)。

| 环节 | 普通客人 | 惊喜客人 |
|---|---|---|
| 入座 | 展示座位Q版静态图 | 展示座位Q版静态图，可显示惊喜来访提示 |
| 点单 | 仅此环节显示点单对话形象与订单台词，不展开闲聊 | 可与老板进行角色专属对话，并完成点单 |
| 等待 | 订单、耐心条、倒计时、符号或短气泡 | 同样显示服务状态，剧情可配置专属对话 |
| 送餐/送饮品 | 在座位直接完成，用图标、数字、短文字反馈，不弹人物立绘对话 | 正常送达，可按剧情触发专属对话 |
| 收钱 | 在座位直接收款，显示金额，不弹人物立绘对话 | 正常收款，可按剧情配置收尾对话 |
| 离场 | 静态图消失或轻量淡出 | 同样处理，不要求专属离场动画 |

普通客人的再次询问属于订单回看，可复用同一张点单形象；不能重复创建订单或重置耐心。座位短气泡和机制提示不是剧情对话。惊喜客人不要求每次送达/收款都触发剧情，先写实际台词与触发条件，再决定需要哪些表情，不统一凑固定数量。

### 座位状态与计时

待点单、等待制作/送达、饮用、待收款、特殊事件均复用同一张座位Q版图，通过订单图标、计时条、数字和短文字区分。面向客人减慢耐心、错送惩罚、收款期限、小费、连击、辅助模式与重试沿用既有地图规则。

点单界面与惊喜剧情对话沿用“弹窗暂停营业”：营业、所有客人耐心、制作、饮用、收款及特殊事件计时统一暂停；普通座位提示不暂停。关闭弹窗当帧隔离输入，防止误送杯或重复收钱。惊喜对话需支持推进/跳过，跳过文本不能跳过实际服务或触发重复奖励。该统一行为需在后续实现中核验。

### 客人美术：三种用途

| 用途 | 普通客人 | 惊喜客人 |
|---|---|---|
| 座位形象 | 1张场内Q版透明静态图 | 1张场内Q版透明静态图 |
| 点单/对话形象 | 1张固定点单形象，只用于点单及订单回看 | 基础对话形象＋实际剧本所需表情差分 |
| 客人图鉴详情立绘 | 必须有完整清晰的角色立绘 | 必须有完整清晰的角色立绘，默认展示基础表情 |

三种用途均需配置，但不等于每人必须重画三张原稿：点单形象可以从已确认的图鉴立绘适配或裁切；惊喜客人也可共用基础立绘。场内Q版与精细立绘分开配置，不把精细立绘默认当作合格座位图，也不能仅用小头像替代图鉴详情立绘。已有确认素材优先复用，保留物种、服装、道具与角色性格；缺图明确待制作/确认，不借用其他客人形象。

图鉴在完成有效收款后解锁，详情展示人物立绘、姓名/身份、小传及已定饮品信息；列表头像可由立绘裁切。未知客人保留未解锁表现，跨日保存收集进度。图鉴展示不算营业对话，不受“普通客人仅点单展示对话形象”的限制，也不需要新增图鉴动画。

不制作客人行走、八方向转身、入场分镜、逐帧饮用、送餐/收钱动作与专属离场动画。静态图淡入淡出、描边与位置变化由程序完成。普通客人不额外制作开心/不耐烦表情组；惊喜客人按实际剧情补表情。小葵已有确认转向与服务动作保留，本次不追加其动作数量。

### 开发交接与验收

- 普通客人只在点单/订单回看显示对话形象；送达、收钱、等待及特殊机制反馈在座位完成。
- 惊喜客人可与老板对话；剧情、表情、触发和重访处理按角色配置，不能重复下单或领奖。
- 对话统一暂停相关计时，关闭当帧不触发场内误操作。
- 座位Q版、对话形象、图鉴详情立绘分别检查，允许后两者复用原稿；每个已解锁客人的详情必须能显示正确立绘。
- 保留特殊机制、地图数值、现有素材和收集/重试规则。运行接入、图鉴展示与实际试玩尚待验收。
