## 制作/接入规范

- PNG真透明，单件独立画布；文字、计数、时间、商品价格由引擎渲染。
- 九宫格只用于适合伸缩的矩形底板。订单气泡尾部必须保护，可拆分或定比例缩放，不拉歪尾巴；圆按钮只能等比缩放。
- 常态先确认。悬停/按下/禁用优先使用程序亮度、轻缩放、灰化，不为每个按钮重复绘制三套。
- 缩小到实际UI尺寸检查清晰度；当前仅验证PNG尺寸/Alpha，尚未完成游戏内布局验收。
- 确认图中的数值只是排版示例，不能反向改变玩法参数。图二只参考提示风格；客人继续直接落座。
