## 小批次顺序

每轮最多两个明确任务。不通过本轮验收，先修复，不开新系统。

| 轮次 | 本轮任务（最多2项） | 验收结果 |
|---|---|---|
| 1 | 导入Unity并修复编译/运行阻断；完成一局Day1冒烟验收 | 开始到结算完整可玩，无阻断报错，收钱/入账不重复 |
| 2 | 对齐主画面布局；修复点击/弹窗输入 | 16:9与16:10可读，订单不挡客人，弹窗不穿透且暂停计时 |
| 3 | 补Horn独立图与桌前遮挡；统一首日角色比例 | 三位客人不带合影底色，人物与桌子前后关系正确 |
| 4 | 小葵转向/服务动作；客人入离场动作 | 状态看得懂，无明显穿模；先满足固定位置服务，不做自由寻路 |
| 5 | 完成首日情境教学；补订单/耐心/完成反馈 | 新玩家不用读文档能接单、取杯、送达、收钱 |
| 6 | 提取关卡/客人/饮品配置；加入版本化存档 | Day1行为不变，可配置后续日程，旧存档能迁移 |
| 7 | Tank素材与两段互动；Gecko素材与换座机制 | 单独验证两客，换座不丢订单、不重复占位 |
| 8 | Day2编排与解锁；失败重试 | Day1通关进入Day2，失败只重试当天，目标有失误余地 |
| 9 | Mimi素材与偷钱预警；SPF-8素材与双杯订单 | 偷钱可打断，双杯不会一杯提前结算 |
| 10 | Day3编排；新机制短提示 | 两个新机制可在实际营业节奏中完成，队列不死锁 |
| 11 | Snowy素材与限时事件；Jiwoo素材与惊喜来访 | 两位都有小传与解锁记录，惊喜来访不会被占座逻辑跳过 |
| 12 | Day4综合编排；第一地图通关演出 | 四天连续打通，显示下一站入口，不实现下一地图 |
| 13 | 三件装饰实物/装备显示；购买保存与加成回归 | 购买扣款一次、摆件可见、重启保留、效果不重复叠加 |
| 14 | 九位客人图鉴/挑战备注；收集进度保存 | 每个解锁条件可复现，未知客人不提前泄露，重启保留 |
| 15 | 提示音/静音与辅助模式；难度调整 | 关键事件有清晰反馈，连续失败可选择降低难度 |
| 16 | 新存档四日完整回归；桌面构建交付 | 可运行构建通过完整通关、重试、购买、存档与分辨率验收 |
